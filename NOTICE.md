# Notices and sources

web-design-suite is an original consolidation: rules from the sources below were read in full, deduplicated, shortened, rewritten and merged into new reference files, with disagreements resolved in `skills/web-design-suite/references/conflicts.md`. No source file is copied wholesale. Where a rule, value table or code snippet is adapted from a source, that source's licence applies to the adapted portion, and its copyright notice is reproduced here.
